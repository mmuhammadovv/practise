# Cyber Path — тренажёр по кибербезопасности

Сайт с 4 уровнями по плану из [PLAN.md](PLAN.md): сети, архитектура ОС, Linux и Windows, основы безопасности.
В каждом уровне 9 задач: тесты, ввод ответа и мини-терминал, где нужно найти флаг.
Следующий уровень открывается, когда решено 7 из 9 задач (75%).

Прогресс хранится в аккаунте, поэтому одинаков на Mac, Windows и телефоне.

## Как устроено

| Часть | Где |
|---|---|
| Страницы (HTML, CSS, JS) | `public/` → Cloudflare Pages |
| API: регистрация, вход, проверка ответов | `functions/api/[[path]].js` → Cloudflare Pages Functions |
| Задачи и правильные ответы | `src/tasks.js` (ответы остаются на сервере) |
| Пароли и сессии | `src/auth.js` |
| База: пользователи, сессии, прогресс | Cloudflare D1, схема в `schema.sql` |

Безопасность входа:
- пароли хранятся как PBKDF2-SHA256 со случайной солью;
- сессия лежит в HttpOnly-cookie, а в базе хранится только хеш токена;
- после 10 неверных паролей вход блокируется на 15 минут;
- POST-запросы принимаются только со своего сайта (защита от CSRF).

## Запуск у себя на компьютере (Mac или Windows)

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
npm install
```

```bash
npm run db:init:local
```

```bash
npm run dev
```

Откройте http://localhost:8788.

## Публикация на Cloudflare (бесплатно)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com).
2. Войдите в Cloudflare из терминала (откроется браузер):

   ```bash
   npx wrangler login
   ```

3. Создайте базу данных:

   ```bash
   npx wrangler d1 create cyber-path-db
   ```

   Скопируйте `database_id` из ответа в файл `wrangler.toml`.

4. Создайте таблицы в базе:

   ```bash
   npm run db:init
   ```

5. Опубликуйте сайт:

   ```bash
   npm run deploy
   ```

   Wrangler покажет адрес вида `https://cyber-path.pages.dev`. Откройте его на любом устройстве и войдите в свой аккаунт.

После изменений в коде повторяйте только шаг 5.

## Как добавить задачу

Откройте `src/tasks.js` и добавьте объект в массив `tasks` нужного уровня.
Примеры всех трёх типов (`choice`, `text`, `terminal`) там уже есть.
Для терминальной задачи укажите файлы в `terminal.files`, например `{"/home/student/flag.txt": "flag{...}\n"}`.
