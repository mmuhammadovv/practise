# План: старт в кибербезопасности за 4 недели

Темп: 1,5–2 часа в день, 5–6 дней в неделю.
Каждая неделя = **уровень** на будущем сайте. Чтобы открыть следующий уровень, нужно решить задачи текущего и пройти итоговый тест.

---

## Уровень 1 — Сети (неделя 1)

**Что изучить**
- Модели OSI и TCP/IP: какие уровни и что на каждом происходит
- IP-адреса, маски, подсети (CIDR: /24, /16 и т.д.), частные и публичные адреса
- TCP и UDP, рукопожатие TCP (SYN → SYN-ACK → ACK)
- Порты и сервисы: 22 SSH, 53 DNS, 80 HTTP, 443 HTTPS, 21 FTP, 3389 RDP и др.
- Протоколы: DNS, DHCP, ARP, HTTP/HTTPS, ICMP
- Что такое NAT, роутер, свитч, файрвол

**Практика**
- Команды: `ping`, `traceroute`/`tracert`, `ipconfig`/`ip a`, `nslookup`/`dig`, `netstat`/`ss`
- Wireshark: поймать свой трафик, найти DNS-запрос и TCP-рукопожатие
- `nmap` — просканировать только свой компьютер или свою виртуалку

**Задачи для сайта**
- Посчитать подсеть: сеть, broadcast, количество хостов для `192.168.10.37/26`
- Сопоставить порт и сервис
- Расставить уровни OSI по порядку
- Найти «флаг» в выводе команды или в дампе трафика

## Уровень 2 — Операционные системы (неделя 2)

**Linux (основной упор)**
- Файловая система: `/etc`, `/home`, `/var/log`, `/tmp`, `/bin`
- Навигация и файлы: `ls`, `cd`, `cat`, `grep`, `find`, `less`
- Пользователи и группы, `sudo`, файлы `/etc/passwd` и `/etc/shadow`
- Права доступа: `rwx`, `chmod 755`, `chown`, SUID
- Процессы и сервисы: `ps`, `top`, `kill`, `systemctl`
- Логи: `/var/log/auth.log`, `journalctl`
- Основы bash: переменные, пайпы `|`, перенаправление `>`

**Windows (база)**
- Пользователи и UAC, реестр, службы
- PowerShell: `Get-Process`, `Get-Service`, `Get-LocalUser`
- Журнал событий (Event Viewer): входы в систему, ошибки

**Практика**
- Поставить Linux в VirtualBox (Ubuntu или Kali)
- OverTheWire **Bandit**, уровни 0–15

**Задачи для сайта**
- Перевести права `rwxr-x---` в число и обратно
- Найти в логе неудачные попытки входа и IP злоумышленника
- Выбрать правильную команду под задачу
- Мини-терминал: найти скрытый файл с флагом

## Уровень 3 — Структуры данных и скрипты (неделя 3)

**Что изучить**
- Основы Python: переменные, условия, циклы, функции, работа с файлами
- Структуры данных: строки, списки (массивы), словари, множества, стек и очередь
- Кодировки: двоичная, hex, Base64, ASCII
- Хеширование и шифрование — в чём разница; MD5, SHA-256; симметричное и асимметричное шифрование
- Форматы данных: JSON, логи, CSV

**Практика**
- Скрипт, который читает лог и считает попытки входа по IP (словарь)
- Простой сканер портов на `socket` (только для своего компьютера)
- Скрипт, который кодирует и декодирует Base64 и hex

**Задачи для сайта**
- Декодировать строку (Base64 → текст, hex → текст)
- Определить тип хеша по виду
- Какая структура данных подходит для задачи
- Дописать функцию на Python (подсчёт, поиск, фильтр)

## Уровень 4 — Основы безопасности (неделя 4)

**Что изучить**
- Триада CIA: конфиденциальность, целостность, доступность
- Типы угроз: фишинг, вредоносное ПО, брутфорс, MITM, DoS, социальная инженерия
- Веб-уязвимости (OWASP Top 10): SQL-инъекция, XSS, слабая аутентификация
- Пароли: хеширование с солью, 2FA, менеджеры паролей
- Защита: файрвол, обновления, принцип наименьших привилегий, бэкапы
- Законность: атаковать можно только свои системы и учебные стенды

**Практика**
- PortSwigger Web Security Academy: первые лабы по SQLi и XSS
- picoCTF — лёгкие задачи
- TryHackMe — бесплатные комнаты из Pre Security / Intro to Cyber

**Задачи для сайта**
- Найти признаки фишинга в письме
- Найти уязвимость в куске кода (SQLi/XSS)
- Определить тип атаки по описанию или логу
- Итоговый мини-CTF: несколько флагов по всем четырём темам
